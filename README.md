# محاسبة اليوم – خطوات التشغيل

التطبيق ده **PWA**: صفحة ويب بتتثبّت على الموبايل وتشتغل كأنها أبلكيشن، بأيقونة على الشاشة الرئيسية ومن غير نت. مش محتاج Play Store ولا App Store.

## محتويات الفولدر

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق نفسه |
| `config.js` | إعداد Firebase (متابعة العيلة) |
| `manifest.json` و `sw.js` | تخلّي التطبيق يتثبّت ويشتغل من غير نت |
| `icons/` | أيقونات التطبيق |
| `firestore.rules` | قواعد الأمان لقاعدة بيانات Firebase |

---

## الخطوة ١: نشر التطبيق على النت (٣ دقايق، مجاناً)

1. فك ضغط الفولدر `muhasaba-app` على الكمبيوتر.
2. افتح **https://app.netlify.com/drop** واعمل حساب مجاني (ينفع بحساب جوجل).
3. اسحب فولدر `muhasaba-app` كله وارميه في الصفحة.
4. هيديك رابط زي `https://random-name-123.netlify.app`.
5. (اختياري) من **Site configuration > Change site name** غيّر الاسم، مثلاً `muhasaba-adel`، فيبقى الرابط `https://muhasaba-adel.netlify.app`.

> التطبيق كده شغال بالنسخة الأولى: كل واحد يسجّل على موبايله ويبعتلك ملخص الأسبوع على واتساب.

## الخطوة ٢: التثبيت على الموبايل

- **أندرويد (Chrome):** افتح الرابط ← هيظهر شريط "تثبيت" فوق، أو من قائمة ⋮ اختار **Install app / تثبيت التطبيق**.
- **آيفون (Safari لازم):** افتح الرابط ← زر المشاركة ⬆︎ ← **Add to Home Screen / إضافة إلى الشاشة الرئيسية**.

---

## الخطوة ٣: تفعيل المتابعة المباشرة للعيلة (١٠ دقايق، مرة واحدة)

### أ. عمل مشروع Firebase
1. افتح **https://console.firebase.google.com** بحساب جوجل.
2. **Create a project** ← اسم المشروع مثلاً `muhasaba-family` ← اقفل Google Analytics ← **Create project**.

### ب. تفعيل الدخول التلقائي
3. من القائمة الجانبية: **Build > Authentication > Get started**.
4. تبويب **Sign-in method** ← اختار **Anonymous** ← فعّله **Enable** ← **Save**.
5. تبويب **Settings > Authorized domains** ← **Add domain** ← اكتب دومين موقعك، مثلاً `muhasaba-adel.netlify.app`.

### ج. قاعدة البيانات
6. **Build > Firestore Database > Create database**.
7. اختار مكان قريب (مثلاً `eur3 (europe-west)`) ← **Start in production mode** ← **Create**.
8. تبويب **Rules** ← امسح كل اللي فيه، والصق محتوى ملف `firestore.rules` ← **Publish**.

### د. ربط التطبيق
9. علامة الترس ⚙️ جنب **Project Overview** ← **Project settings**.
10. تحت **Your apps** اضغط أيقونة الويب `</>` ← اكتب أي اسم ← **Register app** (من غير Hosting).
11. هيظهرلك كود فيه `const firebaseConfig = { ... }`. انسخ اللي بين القوسين `{ }`.
12. افتح `config.js` بأي محرر نصوص (Notepad مثلاً)، وغيّر السطر:
    ```js
    window.FIREBASE_CONFIG = null;
    ```
    لـ:
    ```js
    window.FIREBASE_CONFIG = {
      apiKey: "...",
      authDomain: "...",
      projectId: "...",
      storageBucket: "...",
      messagingSenderId: "...",
      appId: "..."
    };
    ```
13. ارجع لـ Netlify ← موقعك ← **Deploys** ← اسحب الفولدر تاني عشان النسخة الجديدة تتنشر.

### هـ. الاستخدام
- **إنت:** افتح التطبيق ← تبويب **العائلة** ← اكتب اسمك واضغط حفظ ← **إنشاء عيلة جديدة** ← **ابعت الكود** للأولاد.
- **كل ولد:** يثبّت التطبيق من نفس الرابط ← تبويب **العائلة** ← يكتب اسمه ← يكتب الكود ← **انضمام**.
- من بعدها هتشوف كل واحد في تبويب العائلة: نتيجة النهارده وآخر ٧ أيام بالألوان.

## ملاحظات مهمة

- **كل واحد بيعدّل تسجيله هو بس.** قواعد الأمان بتمنع أي حد يكتب في تسجيل حد تاني.
- **كود العيلة هو المفتاح.** أي حد معاه الكود يقدر يشوف تسجيلات العيلة، فابعته لأولادك بس.
- **متمسحش بيانات المتصفح أو التطبيق.** الدخول مربوط بالجهاز. لو اتمسح، الولد يدخل الكود تاني، بس تسجيله القديم مش هيرجع مربوط بيه.
- **الخطة المجانية في Firebase** (Spark) كفاية جداً لعيلة، ومش محتاجة كارت ائتمان.
- **التحديثات:** لو عدّلت أي ملف، غيّر `muhasaba-v1` في أول `sw.js` لـ `muhasaba-v2`، وانشر تاني. الموبايلات هتاخد النسخة الجديدة أول ما تفتح التطبيق بنت.
